# 在阿里云轻量应用服务器上部署「任务管理工作台」— 详细教程

本教程带你：买一台阿里云轻量应用服务器 → 把云同步服务部署上去 → 拿到一个公网 IP，
之后任意设备（电脑/手机）访问它、注册账号，就能多端同步任务。

> 全程只需「复制粘贴命令」，不需要懂编程。建议用电脑操作。

---

## 1. 购买服务器（约 5 分钟）

1. 打开阿里云轻量应用服务器：<https://swas.console.aliyun.com>（没账号先注册）。
2. 点「**创建服务器**」。
3. 关键配置按下面选（其余默认即可）：

| 选项 | 建议 |
|---|---|
| 地域 | 选离你最近的（华东：上海/杭州、华南：广州/深圳、华北：北京） |
| 镜像类型 | **系统镜像** |
| 操作系统 | **Ubuntu 22.04 LTS**（或 Ubuntu 24.04） |
| 套餐 | 新用户入门款即可，**2 核 2G 或 2 核 4G**（本项目很小，2核2G 足够） |
| 时长 | 1 年（新用户活动价约几十元） |
| 登录凭证 | 选「**设置密码**」更省事（记好用户名 `root` 和密码） |

4. 付款后，回到服务器列表，等状态变为「**运行中**」。
5. 记下两样东西：
   - **公网 IP**（例如 `47.100.12.34`，在列表页能看到）
   - **root 密码**

---

## 2. 放行 8000 端口（关键 ⚠️）

阿里云轻量服务器默认只开放 22/80/443 等端口，**必须手动放行 8000**，否则网页打不开。

1. 服务器列表 → 点进你的服务器 → 左侧「**防火墙**」标签。
2. 点「**添加规则**」：
   - 协议：**TCP**
   - 端口：**8000**
   - 来源：**0.0.0.0/0**（所有来源，方便各设备访问）
3. 确定。

---

## 3. 连接服务器（网页终端即可，无需装软件）

1. 服务器详情页右上角点「**远程连接**」→ 选「**Workbench 远程连接**」。
2. 在弹出的网页终端里输入 `root` 回车，再输入密码（输入时屏幕不显示，属正常）。
3. 看到类似 `root@xxx:~#` 的提示符，说明登录成功。

> 也可以本地用 SSH 工具（Windows 自带 `ssh root@你的IP`、或 Xshell/WinSCP）。

---

## 4. 把代码放到服务器上（二选一）

### 方式 A：用 Git 拉取（推荐）

前提：代码已经推到 GitHub 或 Gitee（国内用 Gitee 更快；上传步骤见「Render 教程」第 1 节，把 GitHub 换成 Gitee 即可）。

在服务器终端执行（把地址换成你的仓库地址）：

```bash
# 先安装 git（通常已自带）
apt-get update && apt-get install -y git curl

# 克隆代码（下面以 GitHub 为例；Gitee 同理）
git clone https://github.com/你的用户名/task-sync.git
cd task-sync
```

### 方式 B：用 WinSCP 图形化上传（不想用 Git 就选这个）

1. 电脑上下载安装 [WinSCP](https://winscp.net)（免费）。
2. 新建会话：主机名填服务器公网 IP，用户名 `root`，密码填你的 root 密码，连接。
3. 右侧窗口进入 `/root` 目录，把电脑上整个 `task-sync` 文件夹**拖进去**。
4. 回到服务器终端，进入目录：

```bash
cd /root/task-sync
```

---

## 5. 安装 Docker 并启动服务（约 3 分钟）

在服务器终端（确保当前在 `task-sync` 目录里，提示符形如 `root@xxx:~/task-sync#`）执行：

```bash
# 1) 安装 Docker（官方一键脚本，需要能访问外网）
curl -fsSL https://get.docker.com | bash

# 2) 构建并后台启动（-d 表示后台运行，--build 表示构建镜像）
docker compose up -d --build
```

看到类似 `Container task-sync-task-sync-1  Started` 就成功了。

验证是否在运行：

```bash
docker compose ps          # 状态应为 Up / running
docker compose logs        # 看启动日志，应有「任务同步服务已启动」
```

> 如果提示 `docker: command not found`，先退出终端重连一次，或执行 `source /etc/profile` 再试。

---

## 6. 打开网址，注册账号，开始使用

1. 浏览器访问：`http://你的公网IP:8000`（例如 `http://47.100.12.34:8000`）。
2. 点「**登录 / 注册**」→ 切到「**注册**」→ 填用户名、密码（**服务器地址留空**）。
3. 注册即登录，之后就能正常用：新建任务、甘特图、工作记录、归档……
4. **多端同步**：在另一台电脑 / 手机上打开同一个网址 → 登录**同一账号** → 数据自动拉下来。
5. **装成桌面应用**：Chrome/Edge 地址栏右侧点「安装」图标。

> 数据保存在服务器磁盘的 Docker 卷里，**重启服务器不丢**。

---

## 7. 日常维护

```bash
cd ~/task-sync

docker compose ps           # 查看状态
docker compose logs -f      # 实时看日志（Ctrl+C 退出）
docker compose restart      # 重启服务
docker compose down         # 停止并删除容器（数据不丢，卷还在）
```

**更新代码**：把新代码 push 到仓库后，在服务器执行：

```bash
cd ~/task-sync && git pull && docker compose up -d --build
```

**备份数据**：任选其一
- 网页右上角「**导出备份**」下载 `.json`（最简单）。
- 或在服务器执行：`docker compose exec task-sync cat /data/data.json > 备份.json`，再用 WinSCP 下载。

## 8. 安全建议（重要）

**现状说明**：通过 `http://IP:8000` 访问是**明文传输**，登录密码在网络上未加密。
对个人自用、风险较低的场景可以先用；想更安全，三选一：

1. **（最省事）用 Tailscale 组网加密**：服务器和各设备都装 Tailscale，之后用 `http://100.x.x.x:8000` 访问，流量走 WireGuard 加密，**无需开放公网端口、无需备案、无需证书**。对个人工具最合适。
2. **备案 + 域名 + HTTPS**：国内服务器绑定域名必须 **ICP 备案**（免费但要几周），备案后在阿里云申请**免费证书**，用 Nginx 反代到 8000 并启用 HTTPS。
3. **服务器系统内做安全加固**：改 SSH 端口、装 fail2ban 等（进阶）。

> 至少请做到：root 密码设置得复杂一些；8000 端口仅在需要时开放。

## 9. 常见问题

**Q1：网页打不开？**
按顺序查：① 服务是否在跑（`docker compose ps`）；② 阿里云控制台「防火墙」是否放行了 **8000/TCP**；③ 用手机流量（不走家里 WiFi）访问试试，排除路由器问题。

**Q2：`docker compose` 命令报错？**
确保在 `~/task-sync` 目录下执行，且目录里有 `docker-compose.yml` 和 `Dockerfile`（`ls` 查看）。

**Q3：`curl ... get.docker.com` 下载失败/超时？**
换用阿里云镜像源安装 Docker（把第 5 步第 1 条换成）：
```bash
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable" > /etc/apt/sources.list.d/docker.list
apt-get update && apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

**Q4：忘记密码？**
服务器上执行 `docker compose exec task-sync sh`，然后删掉 `/data/data.json`（会清空该服务器上所有账号数据，慎用）。

**Q5：能不用 Docker、直接跑 Node 吗？**
可以。服务器装 Node 后 `cd ~/task-sync && node server.js`，再用 `nohup node server.js &` 或 pm2 守护。但推荐 Docker，重启自动拉起、数据自动持久化。
